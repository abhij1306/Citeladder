# Archived Commerce five-tab plan

This historical plan proposed a product-level competitor catalog, deterministic
SKU matching, comparison snapshots, and a five-tab Commerce surface. It was
superseded by the pre-launch Commerce cutover documented in
`docs/commerce-intelligence.md`.

The active product has four tabs, treats CSV categories as authoritative,
generates category prompts through the existing prompt owner, isolates runs by
`audit_scope="commerce"`, and presents citations as observed alternatives or
sources rather than matched competitor products.
