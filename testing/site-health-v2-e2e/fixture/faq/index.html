Frequently asked questions

Answers to the questions teams ask most often about building and crawling Fixture Co fixture sites.

What is a fixture site?

A fixture site is a small static website whose content never changes, built so crawler tests are deterministic. Every page exists to exercise one classification signal or rule.

How does the crawler classify a page?

The crawler reads the URL path first, then content heuristics such as question headings, price tokens, and bylines, and finally the structured data types. The highest priority matched signal decides the type.

Why did my page classify as other?

A page classifies as other when no signal matches or the summed confidence falls below the threshold. Ambiguous pages are placed in the neutral bucket instead of being forced into a type they do not fit.

Can the classification change between crawls?

Only when the page itself changes. The classifier is deterministic: the same URL and content always produce the same type, confidence, and evidence.
